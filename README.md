# Luxury Highway Rush

A ready-to-play browser driving simulator with luxury cars like Bugatti Chiron, BMW M8, Porsche 911 Turbo, Mercedes AMG GT, and Audi R8.

## Run it

Open `index.html` in the browser, or use a small local server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Controls

- W / Arrow Up: accelerate
- S / Arrow Down: brake
- A / D or Arrow Left / Arrow Right: steer
- Shift: nitro boost
- R: restart after crash

## Notes

This version is made with plain HTML, CSS, and JavaScript so it runs instantly without installation.
